你好，我是 **Sam Peng**，深圳的软件工程师。

近两年专注 AI 工程：开发 MCP 工具，编写 Agent skill 和提示词，用 Copilot、Claude Code 做设计和重构。业余做了 [Knowledge Copilot](https://marketplace.visualstudio.com/items?itemName=zuizuihao.knowledge-copilot-vscode)，一个 VS Code 扩展，把工作区里零散的 Markdown 整理成可检索的 wiki，回答时附上引用。此前十多年做后端与平台开发，涉及金融分析、物流和机器人。

## 写些什么

- **Agent 与交互设计**：客服 Copilot、对话式询价、合同填写、模板回复。AI 在哪一步介入，界面怎么让人看得懂、改得动。
- **文档与知识库**：扫描件抽取、PDF 转 Markdown、切块与混合检索。怎么让模型的回答有据可查。
- **架构与基础设施**：事件驱动的业务处理流程，AWS 上用 Terraform 管理多环境和灾备。

不少文章带了可以直接上手的原型。

- **AI 工具**：MCP、Agent skill 与提示词、LLM-as-judge、Copilot、Claude Code
- **架构与云**：事件驱动架构、AWS（Lambda、SQS、Batch）、Terraform 多环境与灾备、GitHub Actions
- **语言**：C# / .NET、Python、TypeScript、Go
