Hi, I'm **Sam Peng**, a software engineer based in Shenzhen.

For the past two years I've focused on applied AI engineering: building MCP tools, writing agent skills and prompts, and using Copilot and Claude Code for design and refactoring. On the side I built [Knowledge Copilot](https://marketplace.visualstudio.com/items?itemName=zuizuihao.knowledge-copilot-vscode), a VS Code extension that turns scattered workspace Markdown into a searchable wiki and answers with citations. Before that, more than a decade of backend and platform work across financial analytics, logistics and robotics.

## What I write about

- **Agents and interaction design**: support copilots, conversational quoting, contract filling, template replies. Where AI steps in, and how the UI keeps people able to read and correct its work.
- **Documents and knowledge bases**: extraction from scans, PDF to Markdown, chunking and hybrid retrieval. How to keep model answers grounded in sources.
- **Architecture and infrastructure**: event-driven business processing, and multi-environment, disaster-recovery-ready AWS setups managed with Terraform.

Many posts come with a prototype you can try.

## Skills

- **AI applications**: RAG and hybrid retrieval, document extraction (OCR / VLM), agents with human review, generative UI, evaluation sets and metrics
- **AI tooling**: MCP, agent skills and prompts, LLM-as-judge, Copilot, Claude Code
- **Architecture and cloud**: event-driven architecture, AWS (Lambda, SQS, Batch), Terraform multi-environment and disaster recovery, GitHub Actions
- **Languages**: C# / .NET, Python, TypeScript, Go
